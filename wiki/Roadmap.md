# Roadmap

The canonical list lives in
[`ROADMAP.md`](https://github.com/NepaliTools/NepaliTools/blob/main/ROADMAP.md)
in the repository. The short version:

## Now, 0.1

Windows tray host, the Today and Converter modules, offline BS data from 1975 to
2100 with cited overrides, Modules page, Settings, autostart and `Ctrl+Alt+N`.

## Next, 0.2

- macOS menu-bar build sharing the same core.
- Patro module: a clickable BS month grid.

## Later

- Preeti and Unicode conversion.
- Nepali numerals and number words.
- Holidays and tithi, only with a cited, dated dataset.
- Installer and code signing, if the app has users beyond its author.

## Out of scope

Auto-update, telemetry, accounts, cloud sync, and anything that needs the network
at runtime.

Have an idea that is not listed? Open a
[feature request](https://github.com/NepaliTools/NepaliTools/issues/new?template=feature_request.yml).
